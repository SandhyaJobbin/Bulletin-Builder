      How Word formatting maps to the bulletin
      Sections
      Heading 1 starts a new section. Without heading styles, the tool looks for title lines: red or coloured, larger, ALL CAPS, numbered “1.” “2.”, centred or set apart by blank lines. Change it per file with “Find sections by”, and use “Join above” to merge two sections.
      Block labels
      Heading 2/3, a coloured short line (“Car rentals:”), a short bold line, or a single “- Error type” line. The text and bullets under it belong to that block. When most of the file is bold, bold alone doesn’t count.
      One or two labelled blocks
      Side-by-side cards: white with red bullets, then mint with green bullets.
      Three or more labelled blocks in a row
      Numbered rows with a dark title panel. Change this per section with the Layout menu.
      “Scenario 1: Title” (also Step, Case, Part, Tip + number)
      Scenario rows labelled with that name.
      Label “Moderator takeaway”, “Key takeaway” or “Summary”
      The mint takeaway banner.
      Red text
      Red alert box. Paragraphs starting “Note:”, “Important:”, “Crucial Rule:” or “Remember:” become a yellow note.
      Short bullets after a line ending in “:”
      Pills inside numbered rows (negative wording turns red).
      Images
      Images on the same line sit side by side; page-wide images get their own row. Every image opens full size on click.
      Links
      Links inside a sentence become green pill buttons. A line that is mainly a link (“KB Article: …”) becomes a large button. All open in a new tab.
      “A > B > C” lines
      Shown as a chip sequence, first item highlighted.
      Tables, bold, italic
      Tables keep their rows and columns in the bulletin colours; one-cell shaded tables become callout boxes.
